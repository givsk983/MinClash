# MinClash

**简体中文** · [English](docs/README.en.md) · [日本語](docs/README.ja.md) · [한국어](docs/README.ko.md)

Android Root TUN 客户端，内置 Mihomo 和 KernelSU / Magisk 模块。

[下载最新版](https://github.com/givsk983/MinClash/releases/latest) · [更新记录](CHANGELOG.md)

## 设备要求

已 Root 的 ARM64 设备，Android 9 或更高版本，内核支持 TUN。

## 快速开始

1. 安装 `MinClash.apk`，在 KernelSU 或 Magisk 中授予 Root 权限。
2. 首次使用时，在「设置 → 内置模块」安装模块，然后重启手机。
3. 添加 HTTPS 订阅或导入本地 YAML，然后在「概览」启动 TUN。

支持按配置保存应用分流和自定义规则，以及备份与恢复。
