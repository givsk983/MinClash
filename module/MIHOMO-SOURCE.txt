Base commit: 3f27ef39f8c96bbfbc8b0b9bb10f5c9ef60149d8 (upstream v1.19.33).
Modification: optional TCP keepalive, OFF by default, with three user-selected policies.
Conservative: idle 180s / interval 30s; balanced: 120s / 20s; aggressive: 60s / 15s.
All policies use 3 unanswered probes and check kernel support before enabling.
The supervisor sets MINCLASH_TCP_KEEPALIVE only for an explicitly enabled policy.
Missing/invalid policy or unsupported kernel retains upstream connection behavior.
