# MinClash

[简体中文](../README.md) · **English** · [日本語](README.ja.md) · [한국어](README.ko.md)

A Root TUN client for Android with Mihomo and a bundled KernelSU / Magisk module.

[Download latest release](https://github.com/givsk983/MinClash/releases/latest) · [Changelog (Chinese)](../CHANGELOG.md)

## Requirements

A rooted ARM64 device running Android 9 or later, with kernel support for TUN.

## Quick start

1. Install `MinClash.apk` and grant root access in KernelSU or Magisk.
2. On first setup, install the bundled module from Settings, then reboot.
3. Add an HTTPS subscription or import a local YAML file, then start TUN from Overview.

Save per-app routing and custom rules for each profile, and back up or restore your configurations.
