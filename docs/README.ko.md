# MinClash

[简体中文](../README.md) · [English](README.en.md) · [日本語](README.ja.md) · **한국어**

Mihomo와 KernelSU / Magisk 모듈이 포함된 루팅 Android용 TUN 클라이언트입니다.

[최신 버전 다운로드](https://github.com/givsk983/MinClash/releases/latest) · [변경 내역 (중국어)](../CHANGELOG.md)

## 시스템 요구 사항

TUN을 지원하는 커널과 Android 9 이상을 사용하는 루팅된 ARM64 기기.

## 시작하기

1. `MinClash.apk`를 설치하고 KernelSU 또는 Magisk에서 루트 권한을 부여합니다.
2. 처음 설정할 때는 설정에서 내장 모듈을 설치한 뒤 기기를 재부팅합니다.
3. HTTPS 구독을 추가하거나 로컬 YAML 파일을 가져온 뒤 개요 화면에서 TUN을 시작합니다.

프로필마다 앱별 라우팅과 사용자 지정 규칙을 저장할 수 있으며, 설정 백업과 복원을 지원합니다.
