## 真机验证步骤

当前可用设备：2410DPN6CC，Android API 36，KernelSU。验证保留现有订阅、代理选择与通知偏好。

1. 读取模块版本、TUN 健康状态与共享状态；确认本机 HTTPS、热点 DNS 和双向转发计数。
2. 前台启动／停止 TUN，检查概览、通知和磁贴采用相同状态。
3. 共享开关反复开启／关闭，检查自有规则完整安装与清理、原生热点真实 DNS 和共享恢复。
4. 将 App 置于后台、锁屏，检查模块持续运行；中断通知服务后观察心跳超时恢复。
5. 在可用网络条件下切换 Wi-Fi／流量；没有第二网络或第二 SIM 时记录未实测，依赖自动化故障模型覆盖逻辑。
6. 重启未解锁时验证模块独立工作；通知在 Android 允许启动并可读取用户偏好后恢复。此步骤需要用户允许重启与配合解锁。

Android 9–15、Magisk、其他 ROM 及 IPv6-only／NAT64 网络仍需要额外设备验证。测试不得以全局清空防火墙、清除用户应用数据或关闭系统权限限制代替兼容处理。
